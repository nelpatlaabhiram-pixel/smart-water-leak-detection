# Smart Water Leak Detection & Monitoring System

## About the Project

The Smart Water Leak Detection & Monitoring System is a web-based dashboard designed to monitor water usage and detect possible water leaks.

## Features

- Water usage monitoring
- Real-time flow rate
- Leak detection alerts
- Valve status monitoring
- Building and floor status
- Interactive water usage graph
- Dashboard summary report
- Responsive web interface

## Technology Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## Project Type

Hardware-Free Prototype

The current version uses simulated data instead of physical ESP32 and water-flow sensors.

## Future Scope

The system can be extended with:

- ESP32
- Water flow sensors
- Firebase
- Real-time IoT monitoring
